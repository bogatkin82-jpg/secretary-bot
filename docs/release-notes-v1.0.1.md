# v1.0.1 — меньше дублей задач

Небольшой релиз, который исправляет главную проблему ежедневной работы: бот больше не создаёт отдельную задачу под каждую новую реплику одной темы.

## Что изменилось

- **Продолжение задачи обновляет её, а не создаёт дубль.**
  В промпт передаются ID открытых задач текущего чата. Если новая реплика продолжает ту же тему, модель возвращает `id`, и бот обновляет текст/срок существующей задачи.

- **Страховка без участия модели.**
  Если ID не вернулся, задача ищется в том же чате по точному тексту или вложенности: «проверить парковку» и «проверить парковку на планке» считаются одной задачей.

- **Обновление срока.**
  Если у существующей задачи меняется дедлайн, приходит `🔁 Задача обновлена`, а не новая `📝 Задача`.

- **Очистка старых дублей.**
  Добавлен `scripts/dedupe_tasks_dry_run.py`:
  - по умолчанию показывает группы похожих задач и ничего не меняет;
  - `--apply --yes` оставляет самую старую задачу, берёт самый подробный текст и ближайший будущий срок, остальные удаляет;
  - перед изменением создаёт резервную копию SQLite в `data/`.

  На рабочей базе dry-run нашёл 6 групп, после слияния осталось 12 открытых задач вместо 23.
