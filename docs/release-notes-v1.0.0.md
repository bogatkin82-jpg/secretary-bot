# v1.0.0 — первый публичный релиз

Первый стабильный публичный релиз **Secretary Bot** — личного Telegram-секретаря на aiogram 3 и LLM.

Бот подключается к Telegram Business, читает личные переписки, выделяет важное, ведёт задачи и встречи, расшифровывает голосовые и может отвечать от вашего имени в режиме черновика или автоответа.

## Что умеет

- 🔴 Фильтр важности: `low` / `normal` / `high`.
- 📝 Задачи из переписки, сроки, напоминания и кнопки выполнения.
- 📅 Встречи с датой и временем, экспорт в `.ics`.
- 🎤 Расшифровка голосовых и кружков через GigaChat.
- ✍️ Режимы ответов `off` / `draft` / `auto`.
- 🧠 Персона, факты `/faq`, обучение на ваших правках и `humanize`.
- ☀️ Утренний план и 🗞 вечерняя сводка.
- ⏳ Напоминания о чатах, где вы не ответили.
- 🔎 Поиск по переписке через `/ask`.
- 🌙 Ночной режим и 🏝 режим «нет на связи».
- ⭐ VIP-контакты и 🚫 `ignore` с удалением истории.
- 🎂 Дни рождения, 🌦 погода, 🛒 список покупок, 📋 шаблоны.
- ♻️ Восстановление необработанных сообщений после перезапуска.
- 🧹 Ретеншен: удаление данных старше 365 дней по умолчанию.
- 💻 Локальная Ollama с откатом на облако.

## Технические особенности

- Python 3.12, aiogram 3, SQLite (WAL), Docker.
- Провайдеры: GigaChat, YandexGPT, Claude, локальная Ollama.
- Не-root контейнер, UID/GID `10001`.
- Защита от prompt injection: случайный маркер, экранирование, санитизация имён.
- Проверка SHA256 сертификатов Минцифры для GigaChat.
- 10 unit-тестов без реальных ключей и сети.
- Лицензия MIT.

## Установка

```bash
git clone https://github.com/bogatkin82-jpg/secretary-bot
bash secretary-bot/setup.sh
```

Или вручную:

```bash
cd secretary-bot
cp .env.example .env
nano .env

mkdir -p data
sudo chown -R 10001:10001 data
docker compose up -d --build
```

Подробности: [README.md](../README.md) · [English README](../README.en.md).

## Ограничения

- Нужен Telegram Premium и Telegram Business.
- Только личные чаты; группы и каналы не поддерживаются.
- Бот видит сообщения только после подключения.
- Голосовые — только через GigaChat.
- Один владелец и один экземпляр бота.
